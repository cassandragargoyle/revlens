# Issues

Each issue is a markdown file `NNN-slug.md` in this directory, and **that file is the
canonical content** — the description, the reasoning, the acceptance criteria. Finished
issues are archived under [`done/`](done/).

The **index and the status live on GitHub Issues**
([cassandragargoyle/revlens](https://github.com/cassandragargoyle/revlens/issues)), where
issue `#N` is the file `NNN` and the documents call it `INT-NNN`. There is deliberately no
table here: a list kept by hand conflicts on every merge and duplicates what GitHub already
shows.

[`../contributing/ISSUE-MANAGEMENT.md`](../contributing/ISSUE-MANAGEMENT.md) is the
workflow — numbering, creating, archiving.
