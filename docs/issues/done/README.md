# Archived Issues

Issues that reached a terminal status — ✅ Implemented, ✅ Resolved, ❌ Closed — are kept
here as `NNN-slug.md`. Open issues live one level up, in [`../README.md`](../README.md).

Their GitHub issues are closed and mirror these files (`#N` ⇄ `NNN`):
[closed issues](https://github.com/cassandragargoyle/revlens/issues?q=is%3Aissue+is%3Aclosed).
No summary table is kept here, for the same reason it is not kept upstairs.

[`../../contributing/ISSUE-MANAGEMENT.md`](../../contributing/ISSUE-MANAGEMENT.md) is the
archiving workflow.
